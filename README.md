# Customer Behaviour Analysis Dashboard

## 📊 Project Overview

The **Customer Behaviour Analysis Dashboard** is an end-to-end Data Analytics project designed to analyze customer purchasing patterns, subscription behavior, product category performance, and demographic insights.

The project demonstrates the complete analytics lifecycle:

* Data Cleaning & Preprocessing using Python
* Exploratory Data Analysis (EDA)
* SQL-based Business Analysis
* Interactive Dashboard Development in Power BI
* Business Insights & Recommendations

The objective is to help businesses understand customer behavior, identify top-performing categories, and make data-driven decisions to improve customer engagement and revenue.

### 2. Data Cleaning & Preprocessing

Performed using Python (Pandas & NumPy):

## 📌 Key Insights
